ВАЖНО
======
Этот архив — ИСХОДНИК ДЛЯ СБОРКИ, а не файл для виртуального iPhone.
Его нельзя загружать прямо в Appetize: там будет ошибка “No app found in folder”.

КАК ПОЛУЧИТЬ ПРАВИЛЬНЫЙ ZIP БЕЗ MAC
====================================
1. Распакуйте этот архив.
2. Создайте новый пустой репозиторий на github.com.
3. Загрузите ВЕСЬ контент распакованной папки в корень репозитория.
   В корне должны быть TapVerse.xcodeproj, папка TapVerse и скрытая папка .github.
4. Откройте вкладку Actions.
5. Выберите “Create TapVerse Appetize ZIP”.
6. Нажмите Run workflow → Run workflow.
7. После зелёной галочки откройте справа раздел Releases.
8. Откройте самый новый релиз “TapVerse virtual iPhone build”.
9. Скачайте файл TapVerse-Appetize.zip из Assets.
10. Этот файл НЕ распаковывайте. Сразу загрузите его в виртуальный iPhone.

ПРАВИЛЬНЫЙ ФАЙЛ
===============
TapVerse-Appetize.zip
  └── TapVerse.app
      ├── Info.plist
      ├── TapVerse (скомпилированный исполняемый файл)
      └── остальные файлы приложения

Переименовать обычный ZIP в .app или .ipa нельзя: Xcode обязан сначала
скомпилировать приложение под iOS Simulator. GitHub Actions сделает это на Mac.
