# Как запустить TAPVERSE в браузерном iPhone

## Какой файл нужен

Файл `TapVerse-iOS.zip` — это **исходный проект Xcode**, а не готовое приложение.
Для браузерного симулятора нужен файл:

`TapVerse-Simulator.zip`

Внутри него должна находиться собранная папка `TapVerse.app`. Простое переименование исходного ZIP в IPA не работает: приложение необходимо скомпилировать на macOS через Xcode.

## Способ 1 — без собственного Mac, через GitHub Actions

1. Создайте бесплатный аккаунт на GitHub.
2. Создайте новый пустой репозиторий, например `tapverse-ios`.
3. Распакуйте архив `TapVerse-ONLINE-TEST.zip` на компьютере.
4. Откройте папку `TapVerse` внутри распакованного архива.
5. Загрузите **всё содержимое этой папки** в корень репозитория. В корне GitHub должны быть видны:
   - `TapVerse.xcodeproj`
   - папка `TapVerse`
   - папка `.github`
   - файл `BUILD_APPETIZE.command`
6. Откройте вкладку **Actions**.
7. Выберите workflow **Build TapVerse for Appetize**.
8. Нажмите **Run workflow** → **Run workflow**.
9. После зелёной галочки откройте завершённый запуск.
10. Внизу страницы, в разделе **Artifacts**, скачайте `TapVerse-Simulator`.
11. Распакуйте скачанный GitHub-архив один раз. Внутри будет файл `TapVerse-Simulator.zip`.
12. Загрузите именно `TapVerse-Simulator.zip` в Appetize и запустите iPhone.

Важно: не распаковывайте сам `TapVerse-Simulator.zip` перед загрузкой в Appetize.

## Способ 2 — через облачный Mac или обычный Mac

1. Загрузите и распакуйте `TapVerse-ONLINE-TEST.zip` на Mac.
2. Откройте папку `TapVerse`.
3. Дважды нажмите `BUILD_APPETIZE.command`.
4. Если macOS блокирует файл: нажмите по нему правой кнопкой → **Открыть** → **Открыть**.
5. После сборки рядом появится `TapVerse-Simulator.zip`.
6. Загрузите этот ZIP в Appetize.

Также проект можно открыть двойным нажатием на `TapVerse.xcodeproj`, выбрать любой iPhone Simulator и нажать ▶ Run.

## Для реального iPhone

Для настоящего устройства нужен подписанный `.ipa`. Его нельзя корректно создать простым переименованием ZIP. Потребуются:

- macOS и Xcode;
- Apple ID;
- уникальный Bundle Identifier;
- настройка Signing & Capabilities;
- для некоторых способов распространения — платная Apple Developer Program.

Текущий автоматический workflow специально собирает версию **для симулятора**, чтобы проверить приложение в браузере без сертификатов Apple.

## Если GitHub Actions показывает ошибку

Откройте упавший запуск → шаг **Build TapVerse for iPhone Simulator** и сохраните текст ошибки. Чаще всего причиной бывает обновление Xcode на runner; исходный проект при этом остаётся доступен для исправления.
